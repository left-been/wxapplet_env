# v1.0.0 — 分维度设备信息采集 + 本地指纹展示

- 日期：2026-08-16
- 状态：已实现
- 技术形态：原生微信小程序（无框架、无依赖、无构建链）

## 一、版本目标

搭建一个最小可运行的设备指纹采集小程序，按维度收集设备信息并在本地页面分组展示，
生成指纹 ID 用于学习对比。**不**包含网络上报、权限采集、服务端比对（留给后续版本）。

## 三、采集维度表

| 分组 | 数据源 API | 采集字段 | 回退策略 |
|---|---|---|---|
| device 设备信息 | `wx.getDeviceInfo` | brand, model, system, platform, abi, benchmarkLevel | 回退 `wx.getSystemInfoSync` |
| window 窗口信息 | `wx.getWindowInfo` | pixelRatio, screenWidth/Height, statusBarHeight, screenTop, windowWidth/Height, safeArea | 回退 `wx.getSystemInfoSync` |
| app 应用环境 | `wx.getAppBaseInfo` | SDKVersion, version, language, theme, fontSizeSetting, host, enableDebug | 回退 `wx.getSystemInfoSync` |
| network 网络 | `wx.getNetworkType` | networkType, signalStrength | 失败返回空对象 |
| misc 时区/环境 | JS 原生 | timezoneOffsetHours, timezone(Intl), ua(navigator) | 单项 try/catch |
| canvas2d 渲染指纹 | 隐藏 `<canvas type="2d">` | 固定图案渲染后 getImageData 像素采样哈希、尺寸、像素数 | 节点/上下文不可用降级 `unsupported` |
| webgl 渲染指纹 | 隐藏 `<canvas type="webgl">` | UNMASKED VENDOR/RENDERER、GL VERSION、SHADING_LANGUAGE、MAX_TEXTURE_SIZE、MAX_VIEWPORT、扩展数、readPixels 像素哈希 | 同上 + pixelHash 不可用降级 |

通用降级原则：任一维度失败不阻塞整体采集，异常以 `{ unsupported / error }` 字段呈现。

## 四、指纹算法

1. 各分组对象经 `stableStringify` 稳定化（key 排序、嵌套规范化），消除键序抖动。
2. 以 `FPVersion + 稳定JSON` 拼接为种子字符串。
3. 使用 **FNV-1a 32bit** 哈希（`Math.imul` 保证 32 位乘法），输出 8 位 hex。

```
fpId = FNV-1a( FPVersion || stableJSON(categories) )
```

- 指纹版本 `fpVersion` 参与种子，算法升级会导致 fpId 变化（跨版本不可比）。
- Canvas/WebGL 像素采样采用固定步长抽稀（每 16 / 64 字节取一），保证同设备稳定、跨设备区分的低成本实现。

## 五、本地缓存

- key：`fp_demo_device_id`
- 规则：首次采集写入；再次进入若 `fpId` 未变化则直接复用缓存值（页面仍实时展示最新采集结果）。
- 清除方式：不提供清除入口（学习场景）；后续版本可加「重置指纹」。

## 六、页面交互设计

- 进入自动采集一次（`onReady`）。
- 顶部卡片：设备指纹 ID（monospace 大字）+ 采集时间。
- 操作：`重新采集`（清 loading 重跑全维度）、`复制 JSON`（剪贴板导出 `{fpVersion, fpId, collectedAt, categories}`）。
- 下方按维度分组展示 `key: value`。
- 隐藏 canvas：`position:fixed; opacity:0; z-index:-1`，不占布局。

## 七、兼容与已知限制

- 新拆分 API（2.20.1+）以 `try/catch + 能力探测` 回退旧 API。
- **微信开发者工具**中 Canvas/WebGL 渲染特征基本一致，多设备指纹差异需**真机预览**验证。
- `Intl.DateTimeFormat().timeZone` 部分安卓真机返回 unknown，属平台限制。
- `readPixels` 在部分低端机可能失败，已降级为 `pixelHash='unavailable'`。
- 指纹仅用于学习对比，稳定性/抗伪性远低于商业 SDK（数美/顶象/阿里云）。

## 八、合规说明

- 纯本地采集展示，无任何网络请求，无位置/蓝牙/WiFi 等权限申请。
- 学习用途，不采集 openid 等身份信息。
