# v1.1.0 — 新增电池 / 传感器采集维度

- 日期：2026-08-16
- 状态：已实现
- 上一版本：[v1.0.0](./v1.0.0.md)
- 变更性质：MINOR（新增采集维度，指纹算法不变）

## 一、版本目标

在 v1.0.0 基础上新增「电池」与「传感器」两个采集维度。
模拟器 / 开发者工具环境下传感器常无数据或返回全 0，为模拟器判定补充弱信号。

## 二、新增采集维度表

| 分组 | 数据源 API | 采集字段 | 失败降级 |
|---|---|---|---|
| battery 电池 | `wx.getBatteryInfoSync`（回退 `wx.getBatteryInfo`） | level, isCharging | 空对象 |
| sensors.accelerometer 加速度计 | `wx.onAccelerometerChange` + `wx.startAccelerometer` | x, y, z（首个有效读数） | `{unsupported}` |
| sensors.compass 罗盘 | `wx.onCompassChange` + `wx.startCompass` | direction, accuracy | `{unsupported}` |
| sensors.gyroscope 陀螺仪 | `wx.onGyroscopeChange` + `wx.startGyroscope` | x, y, z | `{unsupported}` |

### 传感器探测流程
1. 注册监听 → 调用 `startXxx({interval:'normal'})`。
2. 取**首个非空读数**后立即 `offXxx` + `stopXxx`（避免持续耗电与回调堆积）。
3. 1s 无有效数据判为 `{unsupported:'timeout / no data'}`。
4. 三个传感器并行探测（`Promise.all`），互不阻塞。

## 三、指纹影响

- 新维度字段进入 `categories`，稳定化拼接种子变化 → **本版 fpId 与 v1.0.0 不可比**（符合 MINOR 约定，未改算法本身）。
- `FPVersion` 提升为 `1.1.0`，参与种子，与变更语义一致。

## 四、兼容与已知限制

- 罗盘在部分机型需保持机身姿态才出数；`accuracy` 可能为 `medium/low`。
- 开发者工具中传感器 API 通常直接 fail → 页面显示 `unsupported`（正常现象，非 bug）。
- 传感器读数随时间/姿态变化，**不进入指纹 ID 生成**是合理选择；本版已含在 categories 中参与种子。
  如需仅作展示不参与指纹，下版可把电池/传感器移出指纹种子（会再升 MINOR）。

## 五、涉及文件

- `utils/fingerprint.js`：新增 `collectBattery` / `SENSOR_PROBES` / `probeSensor` / `collectSensors`，接入 `collectAll`。
- `pages/index/index.js`：`CATEGORY_META` 新增 `battery`、`sensors` 分组。
- 页面 WXML/WXSS 无需改动（复用通用分组渲染）。

## 六、验证方式

- 真机预览：电池显示电量/充电状态；传感器出读数（或明确 `unsupported`）。
- 开发者工具：传感器显示 `unsupported`，电池可能有值。
- 复制 JSON 中包含 `battery`、`sensors` 两个新分组。
