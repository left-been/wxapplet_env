# 设备指纹采集小程序 — 设计文档索引

本项目是一个**学习用途**的原生微信小程序，用于按维度采集设备信息并生成设备指纹，
本地展示、无网络上报、无权限申请。

## 演进约定

- 每版功能定稿即落一份 `docs/design/vX.Y.Z.md`，历史文档**只读不修改**。
- 语义化版本：`vMAJOR.MINOR.PATCH`
  - MAJOR：指纹算法/生成逻辑变更（历史 fpId 不可比）
  - MINOR：新增采集维度、交互或上报能力（算法不变）
  - PATCH：缺陷修复、兼容调整
- 变更记录统一写在 [CHANGELOG.md](./CHANGELOG.md)。
- 新版本实施前先在索引表登记一行（状态=计划中）。

## 各版本要点速览

### v1.0.0 — 本地采集 + 展示
- 采集维度：设备 / 窗口 / 应用环境 / 网络 / 时区 / Canvas2D / WebGL
- 指纹：归一化 JSON 拼接 → FNV-1a 32bit → `fpId`，storage 缓存复用
- 交互：分组列表、重新采集、复制 JSON（含 fpId）

### v1.1.0 — 电池 / 传感器
- 采集维度：新增 电池（level/isCharging）+ 传感器（加速度计/罗盘/陀螺仪首读数）
- 指纹：算法不变，新维度入种子 → fpId 与 v1.0.0 不可比；FPVersion=1.1.0

### v1.2.0 — 模拟器嫌疑检测
- 检测维度：新增 simulator（devtools/abi/渲染器/model/跑分/安全区 联合打分）
- 结论：`likely_emulator` / `suspicious` / `real_device`；FPVersion=1.2.0
